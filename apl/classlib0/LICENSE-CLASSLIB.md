# Notice Regarding Original CLASSLIB Source

This notice applies **only** to the files under `apl/classlib0/` and
related original APL source files (`classlib0.atf`, `examples0.atf`,
`solutions0.atf`, `clbutil0.atf`) — that is, the code originally
written by Charles C. Sims. It does **not** apply to this repository's
own tooling, extraction scripts, or translations, which are released
separately under the `Unlicense` (see `LICENSE`).

## Authorship

CLASSLIB was written by Charles Coffin Sims (1937–2017), professor of
mathematics at Rutgers University for 42 years and a pioneer of
computational group theory, to accompany his book *Abstract Algebra:
A Computational Approach* (Wiley, 1984). Nothing in this repository
changes or transfers Sims' original authorship of that code.

## Stated permission

Per a 2020 post on the [NARS2000 forum](https://www.tapatalk.com/groups/nars2000/apl-abstract-algebra-library-classlib-t640.html),
user `dougt719` ("Doug") stated that he held an email from Professor
Sims, sent prior to Sims' death in October 2017, stating that CLASSLIB
could be posted on the Internet "with no restrictions." Doug shared
the files with NARS2000 forum maintainer Bob Smith. The copy in this 
repository was obtained directly from Bob Smith.

**This repository has not independently verified the original email.**
No copy of the Sims → Doug correspondence is included here. This
notice describes what has been publicly stated, not a confirmed legal
fact.

## What this means in practice

  rights, commercial use, warranty disclaimers — were ever spelled
  out. Anyone relying on this code should understand it as informally

- If you are Charles Sims' heir, estate representative, or otherwise
  hold rights to this material and have concerns about its inclusion

- If you hold a copy of the original Sims → Doug email, or can
